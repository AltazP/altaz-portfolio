# Altaz Punja - Portfolio Website

A modern, responsive portfolio website showcasing software engineering projects and experience.

## Features

- **Responsive Design**: Optimized for all device sizes
- **Dark/Light Mode**: Theme toggle with system preference detection
- **Dynamic Content**: Project case studies loaded from JSON data
- **Smooth Animations**: Interactive UI elements and transitions
- **Accessibility**: WCAG compliant with keyboard navigation support

## Tech Stack

- HTML5, CSS3, JavaScript (ES6+)
- Vanilla JavaScript (no frameworks)
- JSON-based content management
- CSS Grid & Flexbox layouts

## Project Structure

```
├── index.html              # Main landing page
├── resume.html             # Resume/CV page
├── work/                   # Case study pages
│   ├── fbs-admin.html
│   ├── strategy-tester.html
│   ├── nba-sim.html
│   └── discrimination-rpg.html
├── assets/
│   ├── css/               # Stylesheets
│   ├── js/                # JavaScript modules
│   └── images/            # Image assets
└── data/                  # JSON data files
    ├── projects.json
    ├── experience.json
    ├── skills.json
    └── case-studies/
```

## Local Development

1. Clone the repository
2. Open `index.html` in a web browser
3. Or use a local server: `python -m http.server 8000`
